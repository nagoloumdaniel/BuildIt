# @nagoloum/cli

## 0.4.0

### Minor Changes

- Squelettes d'architecture générés (dossiers, README, ADR, docs) et affichés dans l'arbre de l'aperçu.
- Ouverture d'un projet local depuis n'importe quel navigateur (Chromium, Firefox, Safari), ajout des fichiers de base manquants.
- Catalogue : COBOL et ses outils, mobile (Expo, React Native, Flutter) et ordinateur (Electron, Tauri).
- Wizard : recherche, navigation par catégorie, grilles 4 colonnes, variables d'environnement manuelles, brouillon conservé au rechargement, « Nouveau projet » réinitialisé.

## 0.3.0

### Minor Changes

- Configurateur web : projet verrouillé après génération (plus de retour possible), bouton Terminer, ouverture du dossier du projet installé, documentation d'installation qui dit où taper chaque commande ; stepper en barre sur mobile ; plan du projet modifiable choix par choix ; lien de partage de production copiable ; graphe de dépendances redessiné avec légende explicative ; architecture en arbre ; écran Cloner fonctionnel en ligne (copie du dépôt dans un dossier choisi) ; avertissement « combinaison expérimentale » supprimé, chaque technologie du catalogue planifiée par les tests.

## 0.2.0

### Minor Changes

- Configurateur web : stepper numéroté avec ligne de progression, transitions entre étapes et annulation de la création ; bulle de détails sur chaque technologie (raison d'incompatibilité, technologies en cause, solution, documentation officielle) ; audit de compatibilité (règle des écosystèmes, catégories réellement cumulatives, conflits déclarés) ; génération en ZIP ou dans un dossier choisi avec installation des dépendances en direct ; architecture du projet commentée ; projets déjà générés réexportables.

### Minor Changes
